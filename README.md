# White Dragon — лендинг для заказа чая

Одностраничный сайт (лендинг) интернет-магазина чая **White Dragon**. Весь код — HTML, CSS и JavaScript — находится в одном файле `white-dragon.html`, поэтому для запуска достаточно открыть его в браузере.

## Общие сведения

| Параметр | Значение |
|---|---|
| Файл | `white-dragon.html` |
| Тип | Одностраничный сайт (landing page) |
| Язык интерфейса | Русский (`lang="ru"`) |

## Дизайн

- Стиль: современный, минималистичный, с большим количеством свободного пространства.
- Палитра: глубокие чайные и земляные оттенки на светлом фоне.

| Цвет | HEX | Применение |
|---|---|---|
| Тёмно-зелёный | `#2f4a3a` | Кнопки, иконки, акценты |
| Глубокий зелёный | `#223629` | Заголовки, CTA-секция |
| Бежевый | `#f6f1e7` | Фон секций, теги |
| Коричневый | `#7a5638` | Hover-состояния, счётчик корзины |
| Светлый фон | `#fffdf9` | Основной фон страницы |

## Структура страницы

1. **Шапка (header)** — фиксированная, с логотипом, меню, иконкой корзины со счётчиком и бургером.
2. **Hero-секция** — крупный заголовок «Настоящий чай от истоков», подзаголовок, кнопка «Выбрать чай» и фоновое изображение.
3. **Каталог** — сетка из 6 карточек чая. В карточке: изображение, тег вида, название, описание вкуса, цена и кнопка «В корзину».
4. **О видах чая** — 6 информационных карточек с иконками: зелёный, чёрный, улун, белый, пуэр, травяной.
5. **CTA-секция** — контрастный блок «Готовы открыть мир настоящего чая?» с кнопкой «Оформить заказ» и параллакс-фоном.
6. **Подвал (footer)** — меню, иконки соцсетей (Telegram, VK, Instagram), способы оплаты.

## Функциональность

- **Счётчик корзины.** Клик по «В корзину» увеличивает число на значке корзины в шапке на +1; счётчик при этом кратко увеличивается в размере.
- **Обратная связь на кнопке.** На 1 секунду текст меняется на «Добавлено!» с зелёной галочкой, кнопка пульсирует.
- **Бургер-меню.** На мобильных устройствах три полоски плавно превращаются в крестик; меню закрывается после выбора пункта.
- **Плавный скролл** по якорным ссылкам меню (CSS `scroll-behavior` и запасной вариант на JS).
- **Динамическая генерация карточек** из массивов данных `products` и `types` в скрипте.

## Анимации и микро-взаимодействия

| Эффект | Реализация |
|---|---|
| Появление секций при скролле (fade-in + `translateY`) | `IntersectionObserver` добавляет класс `.visible` элементам `.reveal` |
| Параллакс фона CTA-секции | Смещение фона по событию `scroll` |
| Изменение цвета кнопок при наведении | CSS `transition` на `background` |
| Увеличение карточек при наведении | `transform: scale()` |
| Пульсация кнопки «В корзину» | `@keyframes pulse` |
| Анимация бургера | Поворот и скрытие полосок через `transform` и `opacity` |

Для пользователей с настройкой «уменьшить движение» (`prefers-reduced-motion`) анимации появления отключаются.

## Адаптивность

- **Мобильные (до 768 px):** одна колонка, бургер-меню, крупные тап-таргеты (минимум 48 px), читаемый текст без зума.
- **Планшеты (от 768 px):** горизонтальное меню, две колонки карточек.
- **Десктоп (от 1024 px):** три колонки карточек, увеличенные отступы секций.

## Запуск

1. Скачайте файл `white-dragon.html`.
2. Откройте его в любом современном браузере.
3. Для корректного отображения иконок, шрифтов и изображений нужно подключение к интернету.

## Возможные доработки

- Подключение серверной части для реального оформления заказа.
- Страница корзины со списком товаров и итоговой суммой.
- Сохранение корзины в `localStorage`.
- Фильтрация каталога по виду чая.
- Замена изображений-заглушек на собственные фотографии.
